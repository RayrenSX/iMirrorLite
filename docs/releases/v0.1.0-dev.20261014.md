# iMirror Lite v6.3 · 2026-10-14 开发预览版

在安卓手机或平板上通过 USB / Wi-Fi 直接显示并控制 iPhone，日常运行无需电脑中转。

## 功能

- USB 投屏与控制，以及无线 AirPlay 投屏 / RemotePairing 控制。
- 最多五指触控，支持拖动、缩放和多指手势。
- 内置开发者镜像，首次准备无需另行下载镜像；设备个性化验证仍需联网。
- 分别保存有线 / 无线的分辨率、帧率和解码器设置。
- 全屏显示、自定义底部三键、主页 / 多任务等快捷操作。
- 优化视频队列和呈现排程，修复运行中修改 USB 设置及无线高分辨率大帧处理。

## 安装

下载并安装附件 `iMirrorLite-v0.1.0-dev.20261014.apk`。支持 Android 9+、ARM64 和 x86_64，APK 内部版本为 `0.1.0-dev`，使用开发签名。

USB 连接需要安卓支持 USB Host / OTG，并在 iPhone 上确认信任。反向控制要求 iOS 18+ 和开发者模式。无线控制首次需要通过 USB 保存配对并准备开发者环境，然后连接同一局域网。

详细使用及构建步骤见 [README](https://github.com/RayrenSX/iMirrorLite#readme)。
